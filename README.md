# Concordia 实时计分（BGA）

> 仓库 / 更新：https://github.com/Dark-Outlaws/concordia-scorer

Board Game Arena 上《康考迪亚》(Concordia) 的用户脚本：常驻浮窗，实时显示所有玩家**「若此刻结束」的终局预估分**，并按六神逐项拆开。

BGA 在康考迪亚里不显示实时分（台子关闭「实时分数」时更是完全藏起来），这个脚本从**公开版面自己算**，把这个空补上。

## 功能

- 常驻浮窗，可拖动、可折叠；只在康考迪亚对局 / 观战 / 回放里出现，别的页静默
- 每位玩家一块：头像（套该局玩家色）+ 名字 + 总分
- **六神明细**：横幅 · 卡数 · 底数 · 分，四列对齐居中
- **顺序固定**：在看的那个置顶，其余按座位号；分数只影响领先高亮，不随分数换位
- 点 ⓘ 展开图例，列出每神的算法；每格悬停也有说明
- 领先者总分标绿

## 安装

1. 浏览器装 Tampermonkey（Chrome / Edge）
2. 新建脚本，粘贴 `concordia-scorer.user.js` 全文
3. 打开 BGA 康考迪亚对局 / 观战 / 回放，浮窗自动出现

## 计分模型

每神一项分 = **底数（版图侧） × 手里该神卡的 vp 之和**。卡自身带 `god` 与 `vp` 字段，无需另建数据表。

| 神 | 底数 | 每单位分 |
|---|---|---|
| VESTA（维斯塔） | 身家 ÷ 10（身家 = 金币 + 货物折价） | 1 |
| JUPITER（朱庇特） | 非砖城市数 | 1 |
| SATURNUS（萨图恩） | 有你房屋的行省数 | 1 |
| MERCURIUS（墨丘利） | 你能生产的货物类型数 | 2 |
| MARS（玛尔斯） | 棋盘上的殖民者数 | 2 |
| MINERVA（密涅瓦） | 对应专家类型的城市数 | 按卡标注 |

再加触发终局者独占的**协和卡 7 分**。

商品折价（官方规则）：**砖 3 · 食 4 · 具 5 · 酒 6 · 布 7**。

## 数据来源

全部取自 BGA 的 `gameui.gamedatas` 与页面 DOM，不依赖任何私有接口：

| 来源 | 取什么 |
|---|---|
| `players[id]` | 金币、商品（会滞后，只当兜底） |
| `_playersUIData[id].game` | 手牌 / 弃牌、仓库、殖民者、`nbCitiesByProductionType` |
| `_cityList` | 每座城的 `province`、`cityToken.productionType`（产出类型） |
| 页面 DOM `counter_*_<id>` | 金币 / 商品的**实时**计数 |
| `cardTable_*` 的样式 | 神祇横幅图（Gods.png）的地址与切片 |

### 三个踩过的坑

1. **`players` 里的钱货会慢半拍**，页面上的 `counter_coins_*` 才是活账 —— 钱货一律读 DOM。
2. **对手的 `nbCitiesByProductionType` 常是空的**（BGA 只替当前玩家算），城市一律从 `_cityList` 自己数。
3. **房屋归属在 `location_arg`**，不在 `player` 字段里。

## 文件

```
concordia-scorer.user.js   油猴脚本（单文件，直接安装）
docs/harvest-snippet.js     数据探针（F12 粘一段，导出 gamedatas 结构与计数）
EXPERIENCE.md               BGA 计分插件的开发经验（可复用到其它 BGA 游戏）
```

> 神祇横幅图 `Gods.png` 是 BGA 的素材，**不随仓库分发**；脚本运行时直接引用它的 CDN 地址（构建号变了会自动跟随）。

## 已知边界

- 神祇横幅按 `Gods.png` 的固定版式切片（整图 324×516，六条各 324×86）；若 BGA 换了图，切片要跟着调。
- 遇到玩家名互为前缀时，日志/认人可能归错（本脚本以页面数据为准，通常不受影响）。
- 「在看哪位」的判定借的是「页面里唯一带明细计数器的那位」，实时分开启时会退回座位序。
